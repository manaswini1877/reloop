## 4 · Test the endpoints (PowerShell / curl.exe)

### 4a · Happy path – get a presigned upload URL

Create a JSON file first (PowerShell doesn't handle inline JSON well with curl.exe):

```powershell
'{"filename":"test.jpg","content_type":"image/jpeg"}' | Out-File -Encoding utf8 body.json

curl.exe -s -X POST https://<ApiUrl>/upload-url `
  -H "Content-Type: application/json" `
  -d "@body.json"
```

Expected response (`200`):

```json
{
  "upload_url": "https://reloop-backend-imagebucket-xxx.s3.amazonaws.com/uploads/<uuid>.jpg?...",
  "image_key": "uploads/<uuid>.jpg"
}
```

### 4b · Upload a file directly to S3 (presigned PUT)

Copy the `upload_url` from the previous response and run:

```powershell
curl.exe -X PUT "<upload_url>" `
  -H "Content-Type: image/jpeg" `
  --upload-file path\to\test.jpg
```

Expected: HTTP `200` with an empty body. The file should now appear in S3 under `uploads/`.

Verify in the AWS Console → S3 → *BucketName* → `uploads/` prefix.

### 4c · Validation error – unsupported content type

```powershell
'{"filename":"doc.txt","content_type":"text/plain"}' | Out-File -Encoding utf8 bad.json

curl.exe -s -X POST https://<ApiUrl>/upload-url `
  -H "Content-Type: application/json" `
  -d "@bad.json"
```

Expected response (`400`):

```json
{
  "error": "Unsupported content_type 'text/plain'. Allowed values: image/jpeg, image/png, image/webp"
}
```

### 4d · CORS preflight – OPTIONS request

```powershell
curl.exe -s -X OPTIONS https://<ApiUrl>/upload-url `
  -H "Origin: http://localhost:3000" `
  -H "Access-Control-Request-Method: POST" `
  -v
```

Look for `Access-Control-Allow-Origin: *` in the response headers.

### Seed demo data ⚠️ writes to DynamoDB

Set your variables (replace with real values from the stack outputs):

```powershell
$API   = "https://XXXXXXXXXX.execute-api.us-east-1.amazonaws.com/prod"

```

Run the seed script (it will ask you to type "yes"):


Or pass the table name directly:

```powershell

```

### Test GET /items

```powershell
$r = Invoke-RestMethod -Method Get -Uri "$API/items"
$r.items | ConvertTo-Json -Depth 5
```

Expected: 4 items, newest first. `confidence` should be a number like `0.82`, not a string.

Check ordering and confidence type:

```powershell
$r.items | Select-Object item, route, confidence, created_at
$r.items[0].confidence.GetType().Name   # should print "Double" or "Int32"
```
