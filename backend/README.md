# ReLoop – Backend

> **Stack:** AWS SAM · Python 3.12 · S3 · DynamoDB · API Gateway (REST)
> **Region:** us-east-1

---

## Prerequisites

| Tool | Minimum version | Install |
|------|----------------|---------|
| AWS CLI | v2 | <https://docs.aws.amazon.com/cli/latest/userguide/install-cliv2.html> |
| AWS SAM CLI | 1.110+ | <https://docs.aws.amazon.com/serverless-application-model/latest/developerguide/install-sam-cli.html> |
| Python | 3.12 | <https://www.python.org/downloads/> *(only needed for local build without Docker)* |
| Docker | any recent | <https://www.docker.com/products/docker-desktop/> *(needed for `--use-container` build)* |

Make sure your AWS credentials are configured:

```powershell
aws configure          # enter Access Key, Secret Key, region = us-east-1, output = json
```

## 1 · Validate the template

```powershell
cd backend
sam validate --template template.yaml --lint
```

Expected: `template.yaml is a valid SAM Template`

---

## 2 · Build

**Option A – local Python 3.12 on PATH:**

```powershell
sam build
```

**Option B – Docker container (use this if Python 3.12 is not found):**

```powershell
sam build --use-container
```

Expected: `Build Succeeded`

> **Stop here and confirm with the team before running this command.**


When prompted:

| Prompt | Answer |

## 4 · Test the endpoints (PowerShell / curl.exe)

### 4a · Happy path – get a presigned upload URL

Create a JSON file first (PowerShell doesn't handle inline JSON well with curl.exe):

```powershell
'{"filename":"test.jpg","content_type":"image/jpeg"}' | Out-File -Encoding utf8 body.json

curl.exe -s -X POST https://<ApiUrl>/upload-url `
  -H "Content-Type: application/json" `
  -d "@body.json"
```

Expected response (`200`):

```json
{
  "upload_url": "https://reloop-backend-imagebucket-xxx.s3.amazonaws.com/uploads/<uuid>.jpg?...",
  "image_key": "uploads/<uuid>.jpg"
}
```

### 4b · Upload a file directly to S3 (presigned PUT)

Copy the `upload_url` from the previous response and run:

```powershell
curl.exe -X PUT "<upload_url>" `
  -H "Content-Type: image/jpeg" `
  --upload-file path\to\test.jpg
```

Expected: HTTP `200` with an empty body. The file should now appear in S3 under `uploads/`.

Verify in the AWS Console → S3 → *BucketName* → `uploads/` prefix.

### 4c · Validation error – unsupported content type

```powershell
'{"filename":"doc.txt","content_type":"text/plain"}' | Out-File -Encoding utf8 bad.json

curl.exe -s -X POST https://<ApiUrl>/upload-url `
  -H "Content-Type: application/json" `
  -d "@bad.json"
```

Expected response (`400`):

```json
{
  "error": "Unsupported content_type 'text/plain'. Allowed values: image/jpeg, image/png, image/webp"
}
```

### 4d · CORS preflight – OPTIONS request

```powershell
curl.exe -s -X OPTIONS https://<ApiUrl>/upload-url `
  -H "Origin: http://localhost:3000" `
  -H "Access-Control-Request-Method: POST" `
  -v
```

Look for `Access-Control-Allow-Origin: *` in the response headers.

## 5 · Delete the stack  ⚠️ destroys all AWS resources in the stack

> **Stop here and confirm with the team before running this command.**  
> Note: the S3 bucket must be emptied manually first, or the delete will fail.

```powershell
# Empty the bucket first (replace <BucketName> with the real value from Outputs):
aws s3 rm s3://<BucketName> --recursive

# Then delete the CloudFormation stack:
sam delete --stack-name reloop-backend --region us-east-1
```

| Variable | Source |
|----------|--------|
| `BUCKET_NAME` | `!Ref ImageBucket` (auto-generated by CloudFormation) |
| `TABLE_NAME` | `!Ref ItemsTable` |
| `BEDROCK_MODEL_ID` | `BedrockModelId` SAM parameter |
| `USE_MOCK` | `UseMock` SAM parameter |

No secrets are hardcoded anywhere. All names come from CloudFormation references or SAM parameters.
